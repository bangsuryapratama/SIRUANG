# 🏫 SIRUANG
**Sistem Penjadwalan Ruangan Kelas dan LAB**

SIRUANG adalah aplikasi berbasis web menggunakan **Laravel (PHP)**, **Bootstrap**, dan **JavaScript**. Aplikasi ini memungkinkan pengguna untuk melakukan booking ruangan, dan admin untuk mengelola data ruangan, jadwal, dan pengguna.

---

## 🔥 Fitur Utama

### 👤 Pengguna (User)
- Melihat jadwal ruangan (kelas/LAB)
- Melakukan booking ruangan
- Melihat riwayat booking

### 🛠️ Admin
- Manajemen data ruangan (tambah/edit/hapus)
- Kelola jadwal ruangan
- Konfirmasi atau tolak booking user
- Manajemen user

---

## ⚙️ Teknologi yang Digunakan

- **Backend**: Laravel 12 (PHP 8.3)
- **Frontend**: Blade, Bootstrap 5, JavaScript
- **Database**: MySQL 
- **Autentikasi**: Laravel Breeze / Laravel Auth
